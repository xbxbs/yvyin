# 余音

Kotlin + Jetpack Compose 原生 Android 播放器，支持本地资料库与在线音源；品牌以 Manifest 引用的 app_name「余音」为准。版本保持 1.6 / code7。

## 当前状态（release 构建通过，新增改动未真机验收）

- 最新交付改为居中短导航，接入 Compose Cupertino；设置仅保留下载路径、在线播放音质和点歌展开，长按版本号才显示开发者选项。信息/音质面板统一浮动毛玻璃，慢歌词使用GPU子像素位移；具体边界及待验证项见 WORKLOG.md 顶部。
- 后续补充了听歌统计、排序持久化、可用时打开 Lyrico 编辑元数据，以及底部液态玻璃开关；液态材质基于当前 Haze 兼容栈实现动态高光，不宣称为 Kyant Backdrop 的真实折射实现。
- 搜索框后续修正版已回归资料库滚动列表本体，不再作为独立悬浮层覆盖分类行。

- 当前修订把设置放入第三个底部入口；紧凑选中态、滚动收起底栏、A–Z/# 拼音索引、在线搜索历史/分段控件、共享封面转场已接入。最终构建与遗留项以 WORKLOG.md 顶部为准，真机交互未代替用户验收。
- 在线封面使用独立无 Cookie 图片客户端，避免播放创建全局 CookieManager 后后续图片全部失败；不改写系统/其他请求的 Cookie。对应隔离、取消和大小限制测试在 `tools/ArtworkCookieCheck.kt`。

- 原内置歌曲、歌词、封面已从应用资源移出，原文件保存在 `dist/legacy-demo-backup/`，不会读取或修改用户音频文件。
- 授权后查询 Android 系统媒体库；拒绝扫描权限仍可通过系统文件选择器导入单曲。无需所有文件访问权限。
- 读取本地标题、歌手、专辑、时长和封面，提供搜索、艺人/专辑/文件夹浏览、本地歌单、播放队列与收藏。后台播放使用原生前台媒体服务与通知。
- 支持 LRC、增强 LRC 与 TTML；逐字效果依赖歌词时间戳。支持手选歌词与持久授权，自动查找受 Android 存储权限限制；缺少歌词时歌词舞台留空，不显示空状态文案。
- 播放页保留既有布局，封面、歌词和内嵌队列互斥。Haze 1.3.1 公共玻璃材质、设置接线、动态背景偏好和封面回调已接入；玻璃与封面仍待用户实测认可。
- 高刷新率设置即时生效；关闭时两个窗口刷新率偏好归零交给系统，创建、恢复与获得焦点均遵循设置。请求高刷不等于实测帧率，系统仍可受省电策略影响。
- 在线曲目与本地曲库分开标识；在线歌单只存歌曲元信息，不冒充已下载的本地音频。在线接口能力按已确认的公开协议接入，音源配置中的音质名称不等于实际播放权限。
- 音源配置包含酷我、酷狗、网易云、QQ 音乐、哔哩哔哩和咪咕：前四者接入搜索/播放/下载，哔哩哔哩仅搜索、播放未验证，咪咕因签名认证未启用。切换音源会清理旧任务，不使用用户凭据或复制第三方私密会话。
- 第三方可用性与内容权限由提供方决定，不能保证全部曲目、音质或下载授权；仅返回 URL 的解析也不能证明实际音频身份。在线请求失败会明确报错，不连续遍历整个在线队列重试。
- 在线下载交给系统 DownloadManager，保存到 `Music/余音/`；完成后可在本地资料库扫描刷新。不提供付费/DRM 绕过。
- 本轮 release 构建通过，显式使用 kotlinx-coroutines-android 1.8.1；Haze 许可已随包收录。TTML 短行采用固定歌词区宽度，修正右声部缩放时向中间漂移；未改既有动画曲线。观感及手势仍待真机确认，最新未完成项见 WORKLOG.md，许可说明见 THIRD_PARTY.md。

以下是此前歌词演示阶段的修订记录，不代表当前还内置示例歌曲。

## 1.6 拖动明暗与长音修正

- 手动浏览不再取消整屏明暗与模糊；阅读位置附近保持可辨认，远处模糊逐级增加至 8dp，播放高亮仍只跟随真正演唱的行。
- 删除长音专属字形缩放、扩散辉光与左右位移；长短音字形大小一致，保留逐字扫光与平滑上浮。
- 更多信息中区分系统报告的刷新率和硬件绘制帧采样，不把请求的 120Hz 当成实测 120fps。

## 1.5 连续滚动与高刷新率

- 请求同分辨率约 120Hz 显示模式，设备不支持时回退；刷新率仍受系统、电源策略与硬件限制，不代表实测稳定 120fps。
- 播放进度读取下沉到独立时间控件和歌词绘制阶段，当前行索引只在换句时触发重组。
- 原生可滚动状态处理手势与惯性，直接接管行坐标；松手等待惯性结束后恢复跟随，不再叠加整页回位和行回位两套动画。快速点句只执行最新跳转。
- 歌词区紧跟封面标题区，减少顶部空白；按参考保留近轻远重的模糊及上下像素渐隐。整体跟随采用柔和弹簧档位，逐字上浮使用起止平滑的曲线。

## 1.4 原生歌词运动与裁切修订

- 不使用 WebView。`AmllSpring.kt` 按 AMLL 0.6.0 的解析求解器和延迟目标队列移植，所有行的位移/缩放由一个帧时钟推进；等待错峰时旧弹簧继续运行，重定向保留速度，跳转清除旧队列。
- 使用上游的缩放弹簧、300/450ms 明暗过渡、400ms 模糊过渡，补充长音强调的缩放、浮动与辉光。
- 每个字绘制预先测量的小布局，不再逐字重复绘制整句；绘制层四周留出模糊/上浮余量。上下渐隐作用于最终像素，取消父级重复硬裁切和整句边缘透明度。
- 音频采样通过微调视觉时钟速度进行校正，正常播放不因每 200ms 采样而倒退；显式跳转仍立即重置。
- 回归入口 `tools/LyricMotionCheck.kt`：解析轨迹、延迟重定向、跳转取消队列、60/120Hz 一致性、错峰、上下边缘透明度和时钟单调性。测试不等于真机视觉或帧率验证。

## 1.3 AMLL 策略适配

- 核对 npm `@applemusic-like-lyrics/core@0.6.0` 的实际发布代码，不再将读取主分支片段等同于运行演示。
- 行位移采用质量 0.9 的弹簧参数换算；普通换句根据间隔选择刚度，跳转使用单独的弹簧与零错峰。位置和速度保留，新的等待任务不会让已运行的弹簧提前停止。
- 错峰从屏幕上方仍可见的行开始累计 50ms，在焦点及后续每行逐步除以 1.05，移除旧版 280ms 截顶。
- 改为索引模糊、独立亮暗遮罩层及 97% 非焦点缩放，不再使用按屏幕像素距离重复压暗的规则。
- 歌词采用内置 Medium 字体、屏宽 8% 字号和 1.2 倍行高，优先在空格处分成宽度均衡的两段，其他断行交给系统平衡策略；不是旧版粗体和硬性 32–34sp 下限。
- 扫光边缘宽度为半个字高；字词按时间戳缓慢上浮 0.05em，至少持续 1 秒并保持到该行淡出，不再每个字做短促正弦跳动。
- 歌词顶栏独立排版：70 宽封面、17 号常规字重的歌名与艺人、22 行高，两行作为整体与封面居中，更多按钮对齐封面中心；不再把主页面文字缩小后直接当作顶栏。
- 页面几何与歌词显现分离：封面保留同一元素做弹簧变换；主态标题与紧凑标题交接，紧凑标题延迟 100ms、歌词延迟 160ms 显现，取消一秒后才完整出现的等待；快速反向切换保留当前状态。
- 浏览器基准源文件见 `tools/amll-benchmark/`；它独立运行原版 AMLL，而 APK 没有 WebView、JavaScript 或 AMLL npm 运行时。
- 保留 AGPL 文本、上游归属与对应源码，见 `THIRD_PARTY.md`。媒体资源不因此获得公开再分发许可。
- 本版不是完整 AMLL 功能移植：尚无对唱、背景伴唱、复杂强调词、逐字音译或全套间奏动画；也未完成 Apple Music / Android 真机逐帧一致性验证。
- 浏览器下载耗时过长，本轮已停止将该基准作为交付前置；尚未拿到浏览器运行画面，不把源码核对或编译通过当作视觉验证。

## 1.2 静态界面校准

- 基于用户提供的当前版与目标截图，统一到 390 宽坐标测量控件；歌词运动引擎保持 1.1 实现，本版不声称修复了歌词动画。
- 标题、艺人和时间使用内置 Inter / Noto Sans SC 子集字体，关闭合成加粗；字号随播放器宽度确定，不再随系统字体样式变化。
- 调整标题与艺人的独立位置，恢复艺人到进度条之间的留白。
- 进度和音量滑条均恢复为参考图归一化厚度 7；切歌图标缩小并修正轮廓、底部图标和无损徽标。
- 背景保留当前歌曲的黑金、紫色配色，提高模糊色块的明暗层次。
- 字体为开源替代字体，并非 Apple 字体；许可证随应用保存在 `assets/licenses/`。
- 字体再生成脚本为 `tools/build_player_fonts.py`，需要 Python fontTools 与上游 Inter / Noto Sans SC 可变字体。

## 1.1 视觉修订

- 封面模式与歌词模式共用同一份封面、歌名、艺人和控制栏，弹簧驱动位置与缩放，不再整页交叉淡化。
- 使用封面提取的黑金与紫色背景，切换歌词时保持连续；去掉旧版额外设计的歌词底栏。
- 正式演唱歌词为 32 行；前 13 行标题和制作人员信息不再作为歌词滚动，相关信息放在歌曲信息页。
- 前奏显示呼吸点，歌词舞台采用固定锚点；播放时 4 秒无操作自动隐藏控制栏，轻触恢复。
- 逐行弹簧延迟调度与已运行的动画分离，避免新目标到来后在延迟期间突然停住。
- 尚未通过目标应用录屏进行逐帧比对；本项目不是 Apple Music 官方客户端。

## 已实现

- 专辑封面、基于封面的模糊背景、无损标识、进度与音量拖动、收藏、单曲播放清单。
- 内置《如诗一般的形容妳》FLAC，使用 Android MediaPlayer 实际解码播放，不依赖网络或存储权限。
- 从原文件提取封面及 Enhanced LRC；45 行、580 个带时间戳片段，按原始时间同步扫光。
- 歌词逐行独立弹簧：按换句原因和间隔选取参数，累计错峰；详见 1.3 说明和 `LyricMotionPolicy.kt`。
- 按行索引调整清晰度，分离缩放与遮罩亮度；左侧缩放原点；支持打断时保留速度。
- 手动拖动歌词时退去焦点效果，松手 3 秒回到自动跟随；轻点歌词跳转。
- 音频焦点管理、拔耳机暂停、收藏与音量保存；离开应用会暂停播放。

## 使用

安装 APK 后点击播放按钮。底部左侧进入歌词模式；再次点击歌词按钮、顶部手柄或系统返回键回到封面模式。
右下打开播放清单；右侧省略号查看音质和歌曲信息；输出按钮可打开蓝牙设置。
这是单曲本地播放器；不包含在线曲库、Apple AirPlay 协议或后台播放服务。
首尾切换按钮用于当前单曲，不表示存在额外歌曲。

## 环境

- Android 8.0（API 26）及以上；Android 12（API 31）以上启用歌词 RenderEffect 模糊。
- JDK 17 或 21、Gradle 8.13、AGP 8.13.0、Kotlin 2.1.0、Compose BOM 2024.12.01。
- compile/target SDK 35。当前 `local.properties` 指向手机 Ubuntu 的 `/usr/lib/android-sdk`。
- 手机 ARM64 构建通过 QEMU 运行 Gradle 缓存中的新版 AAPT2，以兼容 SDK 35；桌面构建时移除 `gradle.properties` 中的 `android.aapt2FromMavenOverride` 并修改 SDK 路径。
- 本机兼容脚本为 `tools/aapt2-compat.sh`，安装在 `/usr/local/bin/aapt2`，依赖 Ubuntu 的 `qemu-user`、`libc6-amd64-cross`、`libgcc-s1-amd64-cross`。

## 构建

在项目目录执行：

```sh
bash gradlew --no-daemon :app:assembleRelease
```

输出 `app/build/outputs/apk/release/app-release.apk`。
Release 为便于本机安装使用 debug signingConfig；正式发布前需更换为自己的发布密钥。

## 更换内置音频

在安装 Pillow 的 Python 3 环境中运行：

```sh
python3 tools/extract_track.py "音频路径.flac" "项目目录"
```

音频需要有内嵌封面和 Enhanced LRC。普通行级 LRC 仅具有行级时间，不能推断真实逐字时间。
